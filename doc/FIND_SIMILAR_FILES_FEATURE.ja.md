# 類似ファイルの検索

[English](FIND_SIMILAR_FILES_FEATURE.md) \| 日本語

**Tools → Find Similar Files…**（類似ファイルを検索）は、フォルダーの中から、おそらく 2 つも要らないファイルを探し出します。

| 方法 | 見つけるもの | 必要なもの |
|--------|-------|-------|
| **Identical files** | 名前が違ったり別のフォルダーにあったりする、内容が同じファイル | 追加で必要なものはありません |
| **Similar images** | サイズ変更、再エンコード、軽い編集をした同じ画像 | 追加で必要なものはありません |
| **Similar videos** | 再エンコードやサイズ変更をした同じ動画、および長い動画から切り出したクリップ | `PATH` 上の [ffmpeg](https://ffmpeg.org) |
| **Similar audio** | 再エンコードした、またはタグを変更した同じ録音、長い録音から切り出した部分、および長いミックスに含まれる曲 | `PATH` 上の [Chromaprint](https://acoustid.org/chromaprint) の `fpcalc`（`brew install chromaprint`、`apt install libchromaprint-tools`） |

検出は [similar-files](https://github.com/crftwr/similar-files) が行い、XeFM がそれを代わりに実行します。必要なものが足りない方法は、何をインストールすればよいかがメニューに表示されます。

## スキャンを実行する

1. スキャンするフォルダーに移動するか、スキャンするフォルダーやファイルを選択します。
2. **Tools → Find Similar Files…** を選び、方法を選びます。

スキャンはすぐに始まり、**独立したプログラムとして実行されます**。動画のスキャンには何時間もかかることがあります。そのまま XeFM を使い続けても、終了してもかまいません。スキャンは続き、次に XeFM を起動したときに、閉じている間に終わったものを知らせてくれます。

ステータスバーの右端に進み具合が表示されます。

```
⠋ Similar videos extract 42%
```

終わるとその旨が表示されます。

```
✓ Similar videos: 12 groups
```

## 結果を見る

その表示をクリックするか、**Tools → Background Jobs…** を開いて、スキャンを選びます。結果はペインの**新しいタブ**に開きます。グループごとに 1 つのフォルダーを持つ[ツリーファイル](TREE_FILES_FEATURE.ja.md)です。元いたフォルダーは自分のタブに残っていて、結果のタブを閉じる（`Ctrl-W`）とそこに戻ります。各グループでは、他のファイルの比較の基準になったファイルが先頭に来ます。

- グループで `Enter` を押すと、そのファイルが表示されます。そこでファイルを表示したり比較したりできます。
- 実際のファイルを削除または移動するには、ファイル（またはグループごと）を選択して `sync_other_to_current` を実行します（[ツリーファイル](TREE_FILES_FEATURE.ja.md#実際のファイルを操作する)を参照）。反対側のペインに、ファイルがどこにあっても 1 つの一覧として表示されます。
- `Backspace` でグループの一覧に戻ります。

**終わるまで待つ必要はありません。** スキャンの実行中にジョブ一覧でそのスキャンを選ぶと、**Look at the groups so far**（ここまでのグループを見る）が選べます。結果はスキャンの進行に合わせて数分おきに書き直され、ペインもそれに追従します。これらのグループは暫定的なものです。スキャンがあとで読むファイルが、既存のグループに加わったり、新しいグループを作ったりすることがあります。スキャンが終わるまでは、ヘッダーにその旨が表示されます。内容が同じファイルのグループは、一度現れたら変わりません。

XeFM が勝手に何かを削除することはありません。どのコピーを残すかはあなたが決めます。

## スキャンを止める

ジョブ一覧で実行中のスキャンを選び、**Stop the scan** を選びます。1 秒ほどで止まり、それまでに見つかったグループは残ります。

止めたり、コンピューターをスリープさせたり再起動したりしても、それまでの作業は無駄になりません。similar-files はすでに読んだものを覚えているので、同じスキャンをもう一度実行すれば、すぐに続きから進みます。

## 知っておきたいこと

- **ローカルフォルダーのみ。** マウントしたネットワーク共有はローカルとみなされます。`ssh://` や `s3://` 上のフォルダーは、今のところここからはスキャンできません。
- **結果は `~/.xefm/scans/` に保存されます。** スキャンごとに 1 つのフォルダーがあり、結果ファイル（`result.xft`）とスキャンのログが入っています。ファイルのそばには何も書き込みません。完了したスキャンのうち、新しいものから 10 件が保存されます。
- スキャンが完了せずに終わった場合（たとえばプロセスが強制終了された場合）は、ジョブ一覧にその旨が表示され、選ぶとそのログが表示されます。
- **similar-files は XeFM に同梱されています**（0.5 以降）。numpy も一緒に入るので、数千本の動画のライブラリでも、グループ分けは 1 時間ではなく数分で終わります。動画と音声のスキャンには、上に挙げたとおり ffmpeg と fpcalc が別途必要です。
- numpy のビルド済みパッケージがないマシン（32 ビット ARM の Linux など）では、XeFM は numpy なしでインストールされ、動画のグループ分けに時間がかかります。どちらを使ったかはスキャンのログに出ます。
