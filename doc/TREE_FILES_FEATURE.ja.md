# ツリーファイル（.xft）

[English](TREE_FILES_FEATURE.md) \| 日本語

`.xft` ファイルには、**ファイルへの参照をまとめたグループ**が入っています。たとえば、スキャンで見つかった似た動画のグループです。各グループには、さまざまなフォルダー（このコンピューター上やサーバー上）にあるファイルが並びます。`.xft` ファイルの上で `Enter` を押すと、アーカイブのようにブラウズできます。

```
scan.xft/
  trip.mp4 (2)/            ← a group
    trip.mp4               ← stands for /Users/me/Movies/trip.mp4
    trip-small.mp4         ← stands for /Volumes/NAS/trip-small.mp4
    trip (copy).mp4
  logo.png (1)/
    …
```

このファイルを自分で書くことはありません。書くのはプログラムです。XeFM の[類似ファイルの検索](FIND_SIMILAR_FILES_FEATURE.ja.md)機能が、similar-files を通じて書き出します。形式は、そうしたプログラムを書く人向けに [XFT_FORMAT.md](XFT_FORMAT.ja.md) で説明しています。

## ブラウズ

- ファイルの上で `Enter` を押すと中に入ります。グループの上で `Enter` を押すとそのグループを開きます。`Backspace` で上に戻り、最上位からはフォルダーに戻って、カーソルはそのファイルの上に置かれます。
- 各エントリには**ファイルに記録された**サイズと日付が表示されるので、遅いサーバー上のファイルのグループもすぐに一覧表示されます。
- エントリの表示（**File → Open With ▸ Viewer**）、2 つの比較（**Select → Compare Selected Files…**）、反対側のペインへのコピーができます。どれも実際のファイルを読みます。
- フォルダーを指すエントリの上で `Enter` を押すと、そのフォルダーに移動します。

## ツリーが足す列

ツリーを書くプログラムは、各ファイルについてさらに情報を記録し、その表示のしかたを指定できます。similar-files は、各ファイルがグループの先頭のファイルにどれだけ似ているかを記録し、サイズの前に **Similarity** 列を出すよう求めます。XeFM はこのような列を、それを求めるツリーの中でだけ表示します。

- **それでソートする。** ソートダイアログ（`sort`）が、いるグループについてその名前で表示します。
- **隠す。** **View → Show ▸** の同じ名前の項目を **Off** にします。
- **自分のレイアウトで使う。** `config.py` では、XeFM はそれを `xft.` にツリーでの名前を続けて呼びます（`xft.similarity`）。`LAYOUTS` の列に書いたり、`LAYOUT_EXTRAS` に変えたいキーだけを書いてツリーの表示のしかたを変えたりできます（例：`'xft.similarity': {'when': 'never'}`）。どちらも、ツリーをまだ開いていなくても使えます。[ファイルリストのレイアウト](FILE_LIST_LAYOUTS_FEATURE.ja.md)を参照してください。

類似度は切り捨てのパーセントで表示するので、`100%` は完全に一致するときだけです。同一ファイルのツリーは、どのファイルも `100%` になるので、この列を求めません。

## 実際のファイルを操作する

ツリーの中のエントリは参照です。ツリーは見つかったものの記録なので、そこでは削除も名前の変更もできません。実際のファイルを操作するには次のようにします。

- **`sync_other_to_current`** で、カーソル位置のエントリの実際の場所を反対側のペインに開き、カーソルをそのファイルの上に置きます。ツリーはそのままです。
- **複数のエントリ（またはグループ全体）を選択して `sync_other_to_current` を実行します。** 反対側のペインに、それらの実際のファイルがどこにあっても 1 つの一覧として表示されます。そこで削除、移動、比較をします。多くのフォルダーに散らばった重複ファイルを手早く片付ける方法です。
- 反対側のペインで `sync_current_to_other` を実行すると、ツリーでハイライトされているエントリの実際の場所に移動します。
- XeFM の外に渡るものは、すべて**実際のファイル**になります。エントリを対応するアプリケーションで開く（**File → Open With ▸ Default App**）、Finder やエクスプローラーで表示する（**File → Reveal in File Manager**）、編集する（**File → Open With ▸ Text Editor**）、パスをコピーする、のいずれもです。

2 つの `sync_…` アクションにはメニュー項目がありません。コマンドパレット（**Tools → Command Palette…**）か、割り当てたキーで実行してください。キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。

## 書き込み中のツリー

時間のかかるスキャンは数分ごとにツリーファイルを書き直すので、終わる前から見始められます。スキャンが続いている間は次のようになります。

- ペインのヘッダーに **"scanning 42% — groups may change"**（スキャン中 42%、グループは変わる可能性あり）と表示されます。
- ファイルが書き直されると、ペインは自動で更新されます。
- グループのファイルが増えたり減ったり、グループの名前が変わったりすることがあります。XeFM はできる限り同じグループにとどまり、グループがなくなった場合はツリーの最上位に戻ります（そのことはログに出ます）。
- 選択中に `sync_other_to_current` を実行すると、選択したグループがまだ変わる可能性があるので、ファイルを開く前に確認を求めます。

同一ファイルのグループは、現れた時点で確定しています。変わる可能性があるのは、似たファイルのグループだけです。
