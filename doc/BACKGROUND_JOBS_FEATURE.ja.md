# バックグラウンドジョブ

[English](BACKGROUND_JOBS_FEATURE.md) \| 日本語

コピー、複製、移動、削除は**バックグラウンド**で実行でき、その間も XeFM を使い続けられます。ブラウズしたり、ファイルを表示したり、別の操作を始めたりすることもできます。

## 操作をバックグラウンドに回す

- **開始を確認されたとき。** Copy、Duplicate、Move の確認ダイアログには **Background** ボタンがあります。操作は進捗ダイアログなしで始まります。Delete にはこのボタンがありません。削除はたいていすぐに終わるからです。それでも長くかかる削除は、進捗ダイアログからバックグラウンドに回せます。
- **実行中に。** 進捗ダイアログの **Run in background** ボタンを押します。もう一つのボタン **Cancel** は、何かを止める前に確認します。

## 実行中のジョブを確認する

ステータスバーの右端にジョブが表示されます。

```
⠋ Copy 42% +1
```

先頭のスピナーはジョブの実行中に回ります。`+1` は、その後ろで待っているジョブの数です。

**ここをクリックする**か、**Tools → Background Jobs…**（`jobs`）を選ぶと、すべてのジョブが一覧表示されます。内容、コピー元とコピー先、進み具合がわかります。一覧は開いている間も更新され続け、最後のジョブが終わると自動的に閉じます。

```
Copy 12 items  ~/photos → s3://bucket/backup — 42% (1.2G / 2.9G)
Move report.pdf  ~/Downloads → ~/Documents — paused, queued (Enter runs it now)
Copy notes.txt  ~/work → ~/backup — queued (Enter removes it)
```

- **実行中のジョブを選ぶ**と、その進捗ダイアログが再び表示されます。そこから進行を見守ったり、キャンセルしたり、またバックグラウンドに回したりできます。
- **一時停止中のジョブを選ぶ**と、そのジョブを今すぐ、進捗ダイアログ付きでフォアグラウンドで実行します。
- **まだ始まっていない待機中のジョブを選ぶ**と、キューから取り除きます。

## 一度に一つずつ

バックグラウンドジョブは、回した順に**一つずつ順番に**実行されます。ジョブ同士はたいてい同じディスクや同じサーバーを取り合うからです。実行中のジョブは常に一つだけです。

別のジョブがバックグラウンドで実行中のときに操作をバックグラウンドに回すと、その操作は**一時停止して順番を待ちます**。一時停止するのは処理中のファイルが終わってからで、ファイルの途中では止まりません。サーバーへの転送をそれほど長く開いたままにすると、タイムアウトするおそれがあるからです。順番が来ると、止まったところから再開します。

フォアグラウンドで始めた操作はキューに並びませんが、実行中のジョブと並んで書き込むこともありません。そのジョブが（やはり処理中のファイルが終わってから）一時停止し、それを待ってフォアグラウンドの操作が始まります。それまで進捗ダイアログには `Waiting for Copy to pause…` と表示されます。フォアグラウンドの操作が終わるか、それをバックグラウンドに回すと、一時停止していたジョブが再開します。その間、ステータスバーには `Copy 42% paused` と表示されます。

つまり、書き込む操作は常に一つだけです。そのおかげで、各操作は別の操作がコピー先に書き込んだものに気づき、黙ってマージやスキップをせずに尋ねることができます（[ファイル操作](FILE_OPERATIONS_FEATURE.ja.md#あとからコピー先に何かが現れた場合)を参照）。

読み取りだけを行うジョブ（タグの読み込み、フラット表示、インデックス検索、ファイルの比較、拡張機能のチェックサム計算など）は、待つことも待たせることもありません。何が実行中であっても、それと並行して実行されます。

## ジョブが応答を求めるとき

バックグラウンドジョブが、コピー先にすでに同じファイルがあるといった問いに行き当たると、そこで止まって待ちます。作業の途中でダイアログが飛び出すことはありません。代わりにステータスバーに次のように表示されます。

```
⚠ Copy
```

この表示はステータスバーの色を反転して強調され、気付けるように最初の 10 秒間は 1 秒に 1 回点滅します。その後は、問いに答えるまで強調されたまま残ります。

これをクリックしてジョブ一覧を開き、そのジョブを選んでください。進捗ダイアログが問いとともに再び表示され、答えると処理が続きます。必要なら **Run in background** でまたバックグラウンドに回せます。

## ジョブが終わったとき

フォアグラウンドの操作と同じことが起こります。ペインが更新され、何をコピー、移動、削除したか、何が失敗したかがログに出ます。

## 終了するとき

バックグラウンドジョブがまだ実行中か待機中の場合、**Quit** はその旨を伝え、**Cancel** が選ばれた状態で始まります。それでも終了すると、ジョブは途中で止まります。すでにコピーされたファイルはそのまま残ります。XeFM は処理中のファイルが後始末されるのを数秒待ってから終了します。

## 類似ファイルのスキャン

[類似ファイルの検索](FIND_SIMILAR_FILES_FEATURE.ja.md)のスキャンも、同じステータスバーの表示とジョブ一覧に現れます。ただし上で説明した意味でのバックグラウンドジョブではありません。それぞれが独立したプログラムとして実行され、XeFM を終了しても実行を続け、一度に一つずつのキューにも数えられません。
