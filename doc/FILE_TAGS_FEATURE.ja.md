# ファイルのタグ

[English](FILE_TAGS_FEATURE.md) \| 日本語

XeFM はシステムがすでに管理しているタグを読み書きします。そのため、XeFM で付けたタグは Finder（あるいは Dolphin や S3 コンソール）に表示され、そちらで付けたタグも XeFM に表示されます。同期させておくべき XeFM 独自のタグ一覧はありません。

## タグを付ける

お気に入りを追加するのと同じコマンド **Go → Add to Favorites…**（`add_favorite`）を実行します。ダイアログには、お気に入りの行の後にタグの行が並びます。タグの行は選択項目に対して、何も選択していなければカーソル位置の項目に対して働きます。

```
Favorite: This directory: projects
Favorite: Under the cursor: notes.txt
Tag: ✓ ● Work
Tag:   ● Urgent
Tag: Edit tags… (notes.txt)
Tag: Manage tags…
```

- **タグの行** にはタグの色が点で表示され（色のないタグは灰色）、選ぶとそのタグの付け外しを切り替えます。✓ はすべての項目がすでにそのタグを持っていることを示し、その行を選ぶとタグが外れます。そうでなければ、その行を選ぶとすべての項目にタグが付きます。行には、使ったことのあるタグと、このセッション中に XeFM がファイル上で見かけたタグが並びます。
- **Edit tags…** は、すべての項目に共通するタグを `Work, Urgent` のような 1 行で開きます。編集して Enter を押すと、
  - 削除した名前はすべての項目から外され、
  - 追加した名前はすべての項目に付けられ、
  - 一部の項目だけが持つタグはそのまま残ります。

  XeFM がまだ見たことのないタグを追加すると、続けてその色を聞かれます。色なしか、Finder の 7 色から選びます。ファイルの保存場所が色を持たない場合（Linux、S3）と、色の名前のタグ（"Red"）では、この手順は省かれます。
- **Manage tags…** はタグそのものを変更します。色の点付きの一覧からタグを選んでから、次のどれかを選びます。
  - **Change color…** は色を変えます。
  - **Rename tag…** は色を保ったまま名前を変えます。新しい名前のタグをすでに持っているファイルでは、2 つが 1 つにまとまります。
  - **Delete tag…** は、そのタグを持つファイルの数を示したうえで、すべてのファイルからタグを外します。

  Finder と同じく、選択項目だけでなく、そのタグを持つすべてのファイルが対象です。macOS では Spotlight がインデックス済みのすべてのディスクからファイルを探します。それ以外の環境や Spotlight で何も見つからない場合は XeFM が現在のディレクトリ以下を検索するので、その外にあるファイルのタグは元のままです。この行は現在のディレクトリがタグを保存できる場所であれば、カーソル位置に何もなくても表示されます。**Change color…** は保存場所が色を持つ場合にだけ表示されます。

その行が先頭にあるので、実行して続けて **Enter** を押せば、これまでどおり現在のディレクトリがお気に入りに追加されます。AFX style では `add_favorite` は `B` にあります。キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。

## タグを見る

タグの付いたファイルには、名前の後ろに最大 3 つの点がタグの色で表示されます。色のないタグは灰色です。Finder のリストには色付きのタグしか表示されず、色のないタグは **情報を見る** に表示されます。XeFM にはタグ名の列がないので、色のないタグも点で表示します。点は行が表示されるにつれてバックグラウンドで読み込まれるため、遅いネットワークフォルダーでも一覧の表示が待たされることはありません。

S3 上や SSH 越しのファイルには点が表示されません。そこでは 1 回の問い合わせごとに別々のネットワークリクエストが必要になるからです。それでも、タグは **Add to Favorites…** と **Search Tags** で使えます。

## タグで探す：View → Search Tags…

**View → Search Tags…** はタグの一覧を色の点付きで表示します。`Work` を選ぶか、一覧にないタグ名を入力すると、ペインには現在のディレクトリ以下で *Work* タグの付いたすべてのファイルが、ほかの一覧と同じように操作できるリストとして表示されます。Backspace で戻ります。macOS では Spotlight が即座に答えます。それ以外の環境や Spotlight で何も見つからない場合は XeFM がフォルダーを検索し、Esc で中止できます。

アクション名は `find_by_tag` です。どのキーマッププリセットでもキーは割り当てられていないので、`KEY_BINDINGS` で割り当てるか、コマンドパレットから実行してください。

一覧からタグを取り除くには、そのタグをハイライトして削除キー（**Shift-Delete**）を押します。これは XeFM の一覧から外すだけで、ファイルのタグはそのまま残ります。

## タグの保存場所

| ファイルの場所 | 使われるタグ | 色 |
|---|---|---|
| macOS | Finder のタグ。Spotlight でも見つかります | あり、Finder の 7 色 |
| Linux | KDE の Dolphin と同じ `user.xdg.tags` | なし |
| Windows | ファイル上の NTFS ストリーム `xefm.tags`（後述） | 保持されます |
| S3 | オブジェクトタグ：各タグは値が空のキーです | なし |
| SSH | リモートシステム自身のタグ：Linux なら `user.xdg.tags`、macOS なら Finder のタグ | リモートに従います |
| アーカイブの中 | 非対応 | — |

Finder の色の名前（"Red"、"Blue" など）を付けた新しいタグには、Finder と同じくその色が付きます。ほかの場所ですでに色を持っているタグは、その色を保ちます。それ以外の新しいタグには追加するときに選んだ色が付き、あとから **Manage tags…** で変えられます。ほかにこの色を設定できるプログラムがない Windows でも同じです。

**Windows** にはシステム全体で使えるファイルのタグがありません。エクスプローラーの「タグ」は特定の種類のファイルの中にしか保存されないため、XeFM はファイル自体の隠しストリームにタグを保存します。タグは、NTFS ドライブ上で名前を変更したり移動したりしてもファイルについていきます。ほかのプログラムからは見えません。FAT や exFAT のドライブ、クラウドフォルダー、アーカイブにコピーした場合や、ファイルの内容だけをコピーするツールでコピーした場合には失われます。XeFM 自身によるコピーではタグは保たれます。

**Linux** はタグを拡張属性に保存します。拡張属性は ext4、btrfs、XFS が対応しています。FAT、exFAT や多くのネットワーク共有は対応しておらず、そこにあるファイルにタグを付けようとすると XeFM がその旨を表示します。GNOME の Files アプリにはこれらのタグは表示されません。

**SSH** ではリモートシステムのツールを使います。Linux では `getfattr`/`setfattr`（`attr` パッケージに含まれます）、macOS では `xattr` です。これらがない場合、XeFM はインストールすべきパッケージ名を表示します。

**S3** のタグは 1 オブジェクトにつき 10 個までで、この上限にはほかのツールが設定したタグも含まれます。値を持つタグ（`owner=ops`）はほかの誰かのものなので、XeFM はそのまま残します。

## コピーと移動

XeFM がファイルをコピーまたは移動すると、コピー先は元のファイルのタグを受け継ぎます。両側がタグを保持できれば、Mac から SSH ホストへ、Linux から S3 へといった、ストレージをまたぐ場合にも働きます。途中でタグが失われるファイルもコピーはされ、ログにその旨が記録されます。
