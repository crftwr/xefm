# ソートダイアログ

[English](SORT_DIALOG_FEATURE.md) \| 日本語

`sort` を実行すると、アクティブなペインの上にソートダイアログが開きます（コマンドパレット **Tools → Command Palette…** からも実行できます）。キーはキーマッププリセットによって異なります。[キーマッププリセット](KEYMAP_PRESETS_FEATURE.ja.md#すべてのキーの一覧)を参照してください。以前の汎用的なソートメニューに代わる、ソート専用の選択画面です。**ソートキー** と **順序** を選び、確定する前にその順序が何を意味するのかを確認できます。

```
┌────────────────────────────────────────────────┐
│ Sort By                                        │
├────────────────────────────────────────────────┤
│                                                │
│  Filename                                      │
│  Extension                                     │
│  Size                                          │
│  Timestamp                                     │
│                                                │
│  Ascending  Descending                         │
│  a.txt → m.txt → z.txt  (A to Z)               │
│                                                │
│ ↑/↓ key · ←/→ order · Enter apply · Esc cancel │
└────────────────────────────────────────────────┘
```

## 操作

- **Up/Down** — ソートキー（Filename、Extension、Size、Timestamp）を選びます
- **Left/Right** — 順序を選びます。Left が Ascending（昇順）、Right が Descending（降順）です
- **F / E / S / T** — 各行の頭文字で、そのソートキーを直接選んですぐに適用します（ダイアログは閉じます）。順序は現在のままです。`sort` にキーがあれば、ソートの変更はそのキーと文字キーの 2 打鍵で済みます。
- **Enter** — 選んだキーと順序を適用します
- **Escape** — キャンセルします。ペインのソートは変わりません
- **マウス** — キーの行をクリックするとそのキーを適用します。Ascending／Descending をクリックすると、ダイアログを閉じずに順序を切り替えます。ダイアログの外をクリックするとキャンセルします

ダイアログは、ペインの現在のソートキーと順序を表示した状態で開き、ソートし直す対象のペインの上に表示されます。

## 説明行

昇順・降順は抽象的には思い描きにくいものです。「タイムスタンプの降順」は新しい順でしょうか、古い順でしょうか。順序の切り替えの下にある行がその答えです。一覧で実際に使われる順序どおりに 3 つのサンプル値を並べ、操作に合わせてその場で更新します。

| キー、順序 | 説明 |
|------------|-------------|
| Filename、昇順 | `a.txt → m.txt → z.txt  (A to Z)` |
| Size、降順 | `1 GB → 1 MB → 1 KB  (largest first)` |
| Timestamp、昇順 | `2024 → 2025 → 2026  (oldest first)` |

## ペインに表示しているものでソートする

ダイアログは、自身のソートキーの後に、ペインが表示しているもののうちソートキーにないものを並べます。既定の[レイアウト](FILE_LIST_LAYOUTS_FEATURE.ja.md)では **Size with folder totals**（組み込みの **Size** はファイルだけを並べます）、Git の状態の追加の情報が表示されていればその状態です。これでソートすると、このフォルダーだけが、ペインがすでに持っている値の順に並びます。値のない行は最後になります。別のフォルダーへ移ると、ペイン自身のソートに戻ります。値がまだ届いている途中のものは、すべての行に値がそろうまでグレー表示です。[ペインに表示しているものでソートする](FILE_LIST_LAYOUTS_FEATURE.ja.md#ペインに表示しているものでソートする)を参照してください。

## 関連するキー

ダイアログを開かずに使うクイックソートのアクションも引き続き使えます。`quick_sort_name`、`quick_sort_ext`、`quick_sort_size`、`quick_sort_date` で、同じものをもう一度実行すると順序が逆になります。メニューバーの **View → Sort By** サブメニューにも同じ 4 つのソートキーがあり、**View → Sort By ▸ Reverse Sort** で順序を切り替えられます。
