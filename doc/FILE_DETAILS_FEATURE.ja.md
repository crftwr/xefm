# ファイルの詳細情報（I キー）

[English](FILE_DETAILS_FEATURE.md) \| 日本語

**I** を押すと、ファイルやディレクトリの詳細情報を表示する、スクロールできるダイアログが開きます。

## 使い方

- **I** — 詳細情報を表示します
  - ファイルを選択している場合は、選択したすべての項目の詳細を表示します
  - 何も選択していない場合は、カーソル位置の項目の詳細を表示します
- **↑/↓** — 1 行ずつスクロールします
- **Page Up/Down** — 1 ページずつスクロールします
- **Home/End** — 先頭／末尾に移動します
- **Q** または **ESC** — 閉じます

## 表示される情報

### ファイル

- **名前**と完全な**パス**
- **種類** — File / Directory / Symbolic Link / Special
- **サイズ** — 読みやすい単位（B、KB、MB、GB）
- **日時** — 最終更新日時と最終アクセス日時
- **アクセス権** — Unix 形式の `rwxrwxrwx`、および所有者とグループ
- **シンボリックリンクのリンク先** — シンボリックリンクの場合

### ディレクトリ

ディレクトリでは、同じ項目に加えて、再帰的な合計と中身の数が表示されます。

- **Total size**（合計サイズ）— 中にあるすべてのものの合計バイト数。読みやすい単位と正確なバイト数で表示します
- **On disk**（ディスク上のサイズ）— ドライブ上で実際に占めている容量
- **Contents**（内容）— 中に含まれるファイルとフォルダーの数（再帰的に数えます）

これらはダイアログが開いた*後で*バックグラウンドで数えられます。ダイアログはすぐに表示され、数え終わるまで数値が増えていくので、大きな（あるいはリモートの）ディレクトリでも UI が止まることはありません。数えている間、その行には *scanning…* と表示されます。読めないサブディレクトリがあった場合は、結果にその数が示されます。ダイアログを閉じると数えるのをやめます。

シンボリックリンクは 1 つのエントリとして数え、リンク先をたどることはありません。そのため、同じツリーの中を指し戻すリンクがあっても合計が膨らむことはありません。

複数の項目を選択している場合は、上部の集計に、選択全体（選択したディレクトリの中身もすべて含む）の **Total size**、**On disk**、**Total items**（ファイルとフォルダーの数）がリアルタイムで表示されます。

#### サイズの行が 2 つある理由

これは Finder が *サイズ* と *ディスク上* として表示するのと同じ 2 つの数値で、ほとんどのフォルダーでは丸めの分しか違いません。どのファイルもブロック単位で容量を占めるからです。フォルダーが、コンパクトに保存されたものを含んでいると、両者は大きく離れます。

- **スパース**ファイル — 大部分が一度も書き込まれていない空き領域のファイルです。代表的なのは仮想マシンのディスクイメージで、長さが 1 テラバイトあっても、占める容量は 20 ギガバイトということがあります
- **圧縮**ファイル — macOS が中身より小さく保存しているファイルです
- **クローン**されたコピー — どちらかが変更されるまで、元のファイルと記憶領域を共有しているコピーです

Docker のディスクイメージを含む `~/Library/Containers` のようなフォルダーでは、**Total size** が 1 テラバイト近くになる一方で、**On disk** は数十ギガバイトということがあります。どちらも正しい値で、削除したときに取り戻せる容量を示すのは後者です。

**On disk** は、測定できる場所、つまり macOS と Linux のローカルドライブでだけ表示されます。Windows のパス、SSH と S3 の接続、アーカイブの中のファイルでは表示されません。これらはどれもこの値を報告しないので、推測にすぎない数値を表示する代わりに省いています。

### 属性

項目自身の情報の下に、その項目に当てはまる属性が言葉で表示されます。**Tags**（タグ）と、自分で定義した属性やインストールした拡張が加える値（Git の状態、写真の寸法、曲の長さなど）です（[ファイルリストのレイアウト](FILE_LIST_LAYOUTS_FEATURE.ja.md#attributes--エントリについて-xefm-が知ることのできる値)を参照）。その値を持たない項目には、その行は表示されません。

ペインにすでに表示されている値はすぐに表示されます。それ以外の値は、ダイアログを開いている間にダイアログ内の項目について求められ（ペインでは求められたときにだけ計算する値も含みます）、届いたものから表示されます。届くまでは *reading…* と表示されます。ダイアログを閉じると止まります。

例：

```
┌─────────────── Details: filename.txt ───────────────┐
│ File: filename.txt                                   │
│ Path: /home/user/documents/filename.txt              │
│ Type: File                                           │
│ Size: 1.2 MB                                          │
│ Modified: 2024-03-15 14:30:22                        │
│ Accessed: 2024-03-15 16:45:10                        │
│ Permissions: -rw-r--r--                              │
│ Owner: user:staff                                    │
└──────────────────────────────────────────────────────┘
```

複数の項目を選択している場合は、それぞれの詳細が区切り線で分けて順に表示されます。

## 注意

- **アクセス権やアクセスのエラー**は適切に処理されます。読めないシンボリックリンクのリンク先は `<unreadable>` と表示され、アクセスできないディレクトリは失敗する代わりに `<permission denied>` と表示されます。
- **Windows** では、所有者／グループは数値の UID/GID で表示されます。
- どちらのペインでも同じように動作し、検索結果や複数ファイルの選択も調べられます（先に **Space** または **A** で選択します）。
